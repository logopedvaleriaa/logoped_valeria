# Логопед | Валерия Выстороп

Адаптивная авторская библиотека на React, TypeScript, Vite, Tailwind CSS и React Router. Сервер и база данных не требуются. Сайт не опубликован.

## Запуск

Требуется Node.js 22.12+ (или 24).

```sh
npm install
npm run dev
```

Откройте адрес, который Vite покажет в терминале (обычно http://localhost:5173).

```sh
npm run build   # проверка TypeScript и production-сборка в dist
npm run preview # просмотр production-сборки
npm test        # проверка поиска, фильтров и каталога (Node 22.18+ или 24)
```

## Структура

- `src/data/materials.ts` — каталог и Telegram-контакт.
- `src/types/material.ts` — тип материала.
- `src/pages/` — главная, каталог, материал и информация об авторе.
- `src/components/` — карточки, изображения с резервным отображением, SEO.
- `src/styles/index.css` — палитра, оформление, адаптивность.
- `public/covers/` — обложки материалов и превью PDF.
- `public/screenshots/` — реальные скриншоты.
- `public/downloads/` — только бесплатные файлы.

## Добавление материала

По пожеланию автора блок «Речевые задачи» не используется ни в окнах, ни на отдельных страницах материалов. Не добавляйте его в новые карточки, описания и шаблоны данных.

Добавьте полный объект в массив `materials` в `src/data/materials.ts`. Каталог содержит только материалы автора; демонстрационные карточки удалены и больше не добавляются. Указывайте `isDemo: false`, для бесплатной браузерной игры — действительный `playUrl`, для бесплатного файла — `downloadUrl`. У платных материалов ссылка на запуск и скачивание остаётся `null`. Тип `Material[]` проверит все поля.

Пример структуры реального объекта (значения и пути замените собственными):

```ts
{
  id: 'unique-id',
  slug: 'unique-material-slug',
  title: 'Название материала',
  description: 'Описание для посетителей',
  sound: 'Р', // Р, Л, С, Ш, Другие
  format: 'PDF', // 3D, HTML, PPTX, PDF
  age: '5–6', // 4–5, 5–6, 6–7 или null, если возраст пока не указан
  price: null, // для платного материала укажите реальную цену в рублях
  isFree: true,
  isDemo: false,
  cover: 'covers/your-cover.svg',
  screenshots: ['screenshots/your-screenshot.jpg'],
  playUrl: null, // реальный полный https-адрес игры
  downloadUrl: null, // реальный URL бесплатного файла
  telegramOrderUrl: null, // индивидуальная ссылка заказа, при необходимости
}
```

Пути обложек и скриншотов указываются относительно `public/`, без начального `/`. Для бесплатного локального файла в `downloadUrl` используйте `${import.meta.env.BASE_URL}downloads/your-file.pdf` (выражение TypeScript, а не строку с буквальными скобками). Сначала разместите существующий файл в `public/downloads/`. Не подключайте несуществующие файлы. Галерея автоматически появляется при заполнении `screenshots`. Неизвестный slug показывает страницу «Материал не найден».

Раздел, поисковый запрос и стоимость хранятся в URL и сохраняются при обновлении страницы. Строка кнопок выбора звука убрана по пожеланию автора; старые параметры `sound` и `sound-*` не ограничивают материалы в каталоге. Звуки остаются в описаниях и данных материалов.

## Структура каталога и покупка

Каталог разделён на браузерные игры (3D и HTML вместе), PowerPoint и материалы для печати. Названия разделов редактируются в `src/data/sections.ts`. Пустые разделы при фильтрации скрываются.

Страница `#/how-to-buy` объясняет заказ через Telegram или ВК. Шаги покупки и ответы на вопросы редактируются в `src/components/PurchaseGuide.tsx`. Краткая инструкция также показана на главной.

## Telegram и действия

Контакт автора `llerrrrrrra` задан в `src/data/materials.ts` (без `@`). Платные материалы с `isDemo: false`, `isFree: false` и положительной конечной `price` получают кнопку «В корзину». Каждый материал добавляется один раз. Не публикуйте выдуманные цены для тестирования.

Корзина `#/cart` показывает список, сумму, удаление отдельных материалов и очистку. Выбор сохраняется в localStorage этого браузера; имя и комментарий не сохраняются. При недоступном хранилище корзина работает до перезагрузки. После обновления каталога удалённые, бесплатные и демонстрационные материалы автоматически исключаются, цены берутся из текущего каталога.

Кнопка «Перейти в Telegram с заявкой» открывает личный чат автора с подготовленным списком, суммой, необязательным именем и комментарием. Покупатель должен сам нажать «Отправить» в Telegram. До этого заявка автору не поступает; сайт не показывает фиктивного подтверждения отправки и не очищает корзину. Есть просмотр и копирование текста для клиентов Telegram, в которых черновик не подставился. Официальный формат ссылки: https://core.telegram.org/api/links#public-username-links. Настройка `telegramOrderUrl` сохранена в типе для совместимости данных, но оформление покупки теперь идёт через общую корзину и контакт `telegramContact`.

Бесплатный материал показывает «Играть», если задан `playUrl`, или «Скачать», если задан `downloadUrl`, и не добавляется в корзину. Для скачивания предпочтительны файлы на том же домене: внешний сервер может открывать файл вместо принудительного скачивания.

Проверки `npm test` используют отдельные тестовые платные материалы, которые не попадают в публичный каталог. Для проверки полного пользовательского сценария добавьте первый настоящий платный материал с согласованной ценой, выберите его, откройте корзину, проверьте список и черновик в Telegram. Для этой проверки не требуется отправлять сообщение. Первый платный материал — «Волшебная страна», 500 ₽. Ссылка запуска и файлы в каталог не включены; доступ передаёт автор после оплаты.

**Не храните платные PPTX/PDF в `public/`, `dist/` или публичном Git-репозитории.** В первой версии автор вручную подтверждает цену, оплату и передаёт файл через Telegram или ВК. Удаление файла из текущей версии Git не удаляет его из истории.

## GitHub Pages — публикация только по вашему решению

1. Создайте репозиторий GitHub и загрузите проект, включая `package-lock.json` (не `node_modules` и не `dist`).
2. В Settings → Pages выберите Source → GitHub Actions.
3. После проверки и решения о публикации откройте Actions → Deploy to GitHub Pages → Run workflow.
4. Дождитесь успешного задания deploy. Адрес будет в результате workflow.

Workflow запускается **только вручную**, push не публикует сайт. В `vite.config.ts` установлен `base: './'`, поэтому assets работают на домене и в подкаталоге репозитория. `HashRouter` даёт устойчивые прямые ссылки вида `https://USER.github.io/REPO/#/materials/derevnya-r` без серверных rewrite и 404. Не удаляйте `#/` из этих ссылок.

Каждая страница обновляет title и description. Поскольку это клиентское приложение с hash-маршрутами, отдельные SEO-превью страниц ограничены; для полноценной индексации отдельных материалов в будущем понадобится prerender или серверный рендеринг.

Шрифты Montserrat (основной текст) и Unbounded (заголовки) загружаются с Google Fonts; при отсутствии сети используются системные шрифты. Все обложки локальные и работают без внешних сервисов.

## Главная и окна игр

При входе на главную без параметров автоматически выбрана кнопка «Все»: все игры и пособия показаны группами по формату с заголовками разделов. Кнопка «Все» расположена перед разделами. Нажатие на раздел оставляет только его материалы; «Все» возвращает все группы. Комплекты с несколькими форматами видны в соответствующих группах, но общие счётчики и корзина учитывают их один раз. Строка выбора звука убрана. Поиск и дополнительные фильтры открываются кнопками рядом с разделами: в левом оглавлении на широком экране и над карточками на телефоне. Нажатие на обложку, название или «Подробнее» открывает нативное модальное окно с описанием и доступным действием. Бесплатная игра запускается в новой вкладке кнопкой внутри окна. Бесплатные файлы доступны кнопкой «Скачать».

Окно закрывается крестиком, Escape или нажатием на затемнение. Пока оно открыто, прокрутка фона блокируется; фокус остаётся внутри окна и возвращается на исходную кнопку после закрытия. Компонент — `src/components/MaterialDialog.tsx`. Прямые ссылки `#/materials/SLUG` продолжают работать как самостоятельные страницы.

## Артикуляционная гимнастика

Для включения материала в тематический раздел «Артикуляционная гимнастика» добавьте `topics: ['articulation']` в его объект. Формат остаётся 3D, HTML, PPTX или PDF. Материал продолжает отображаться в своём формате; в общем счётчике учитывается один раз. Раздел предназначен для отдельных материалов по артикуляционной гимнастике. «Деревня» и «Волшебная страна» в него не включаются, даже если содержат упражнения внутри игры.

Unbounded распространяется по SIL Open Font License 1.1, допускающей коммерческое использование и встраивание: https://github.com/google/fonts/blob/main/ofl/unbounded/OFL.txt.

## Боковая корзина

«Корзина» в меню, нижняя кнопка «Оформить заявку» и «В корзине · Открыть» показывают боковую панель поверх каталога. Она закрывается крестиком, Escape и нажатием на затемнение. Прямая страница `#/cart` также доступна.

В заявке можно указать имя и комментарий. Все поля необязательные, не сохраняются в localStorage и не отправляются автоматически. Выбранные игры сохраняются как прежде. Кнопка перехода открывает Telegram с подготовленным текстом; покупатель сам отправляет его в чате. Для автоматического получения заявок без перехода в Telegram потребуется серверный обработчик, которого в текущей версии нет.

Для добавления связи через ВКонтакте укажите действительный адрес страницы, сообщества или чата в `vkContactUrl` в `src/data/materials.ts`. Кнопка появляется в контактах автора и разделе «Как купить». Пока адрес не задан, кнопка ВК не показывается.

В корзине есть выбор способа связи: Telegram или ВКонтакте. Telegram открывает черновик сообщения; для ВК предусмотрены копирование текста и переход по `vkContactUrl` — автоматическая подстановка сообщения в ВК не заявляется. Пока адрес ВК не задан, выбранный вариант показывает понятное сообщение вместо неработающей кнопки.

Для ВК кнопка «Скопировать заявку и открыть ВК» сначала копирует текущий текст заявки и только после успешного копирования открывает сообщество в этой же вкладке. Так переход не зависит от блокировки всплывающих окон. Пользователь вставляет текст и отправляет его самостоятельно. При запрете доступа к буферу сайт остаётся открыт и показывает выделяемый текст и отдельную ссылку на сообщения. Автоматическое заполнение поля ввода на стороне ВК не обещается.

Раздел «Браузерные игры» использует URL `?format=browser` и включает материалы форматов `3D` и `HTML`. На карточках сохраняется фактическая метка формата. Прежние ссылки каталога `?format=3D` и `?format=HTML` открывают объединённый раздел. Артикуляционная гимнастика остаётся отдельным тематическим разделом для специальных пособий.

## Новинки

Кнопка «Новинки» открывает отдельную подборку (`?topic=new`). В неё попадают только реальные материалы с `isNew: true`; тот же признак включает отметку «Новинка» на карточке. Поиск и фильтр стоимости работают в этой подборке. Чтобы убрать материал из новинок, удалите `isNew` или установите `false`.

## Универсальные игры

Вкладка «Универсальные игры» (`?topic=universal`) предназначена для материалов без привязки к одному звуку. Для добавления игры в неё укажите `topics: ['universal']`. Её исходный формат (3D, HTML, PPTX или PDF) сохраняется. В ней уже есть «4 в ряд». «Деревня» и «Волшебная страна» автоматически в неё не включаются. Названия и тексты пустых тематических вкладок находятся в `src/data/sections.ts`.
